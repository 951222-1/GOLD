# 體感淘金洗泥沙 🪙 (Gold Panning ASMR)

基於 **MediaPipe Tasks Vision** 雙手與肢體姿態追蹤技術打造的純解壓體感淘金遊戲。

🎮 **線上直接遊玩網址**：[https://951222-1.github.io/GOLD/](https://951222-1.github.io/GOLD/)

---

## ✨ 遊戲特色

1. **🌀 雙手畫圓旋轉淘洗**：
   - 雙手在鏡頭前捧著虛擬淘金盤，藉由真實的畫圓旋轉動作帶動水流。
   - 盤內生成動態水流漩渦、水珠氣泡與水花浪滴，體驗 ASMR 般的流水沖刷感。

2. **💧 泥水混濁到澄澈的平滑漸層**：
   - 從沉甸甸的深色河床泥漿逐步沖刷變淡，轉化為澄澈晶瑩的高山溪流水光。
   - 盤底刻痕（Riffles）阻截沉重礦石與寶物，隨水清澈若隱若現。

3. **💎 豐富寶物與逗趣廢鐵怪東西**：
   - **珍稀寶藏**：✨ 天然淘金沙、🪙 西班牙古金幣、👑 天然狗頭金、💎 閃耀紅寶石、🦖 遠古琥珀化石。
   - **逗趣雜物**：🔩 生鏽螺帽、🥫 壓扁可樂罐、👞 破爛泡水鞋、🗝️ 神祕生鏽鑰匙、🧲 廢棄老磁鐵、🦴 深山魚骨頭。

4. **🧘 純粹解壓、無負擔**：
   - 無時間倒數、無失敗懲罰。
   - Web Audio API 原生音效合成：舀水波聲、浪花嘩啦聲、金幣清脆撞擊聲與逗趣廢鐵音效。
   - 影像僅在本機瀏覽器處理，不需上傳伺服器，安全且隱私無虞。

## 🛠️ 技術架構

- **視覺追蹤核心**：Google `@mediapipe/tasks-vision` (HandLandmarker & PoseLandmarker)
- **前端建置工具**：Vite
- **渲染引擎**：HTML5 Canvas 2D 高效能繪圖與物理粒子模擬
- **音效系統**：Web Audio API 原生振盪器與白噪音濾波器合成
- **自動部署**：GitHub Actions + GitHub Pages
